A collection of useful quantum/ classical codes written or adapted by Onri Jay Benally. Some codes are available to run on Google Colab (free, cloud-based programming tool), but may also be compatible with paid GPU cloud tools like Saturn Cloud. Many of Onri's custom code examples here are now used as blueprints to steer modern generative LLMs for high fidelity GPU-accelerated and non-GPU-accelerated scientific computation scripts.
